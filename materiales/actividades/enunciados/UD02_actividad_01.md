# UD02 · Actividad 01 — El modelo Entidad/Relación: conceptos fundamentales

## Objetivo

Comprobar y consolidar la comprensión de qué es el modelo E/R, para qué sirve y en qué fase del diseño de una base de datos se sitúa.

## Contexto

El modelo Entidad/Relación es la herramienta de referencia para representar, de forma independiente del SGBD, la realidad de un problema antes de construir una base de datos.

## Tareas

1. Explica con tus propias palabras qué significa que el modelo E/R sea un **modelo semántico** y por qué esto lo diferencia de un modelo físico de almacenamiento.
2. Indica en qué fase del proceso de diseño de una base de datos se sitúa el diagrama E/R (antes o después del diseño lógico) y justifica tu respuesta.
3. ¿Es correcto afirmar que el modelo E/R solo puede utilizarse para diseñar sistemas informatizados? Justifica tu respuesta.
4. Un compañero afirma que "el modelo E/R Extendido sustituye por completo al modelo E/R básico, ya que es más moderno". Valora si esta afirmación es correcta y explica por qué.
5. Explica qué es el "documento de especificación de requerimientos" y qué papel desempeña en la elaboración de un diagrama E/R.

## Formato de entrega

Respuestas breves (2-4 líneas por pregunta), en texto libre.
