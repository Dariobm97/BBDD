# UD02 · Actividad 02 — Identificación de entidades, relaciones y atributos

## Objetivo

Practicar la extracción de entidades, relaciones y atributos a partir de un texto de especificación, aplicando las pistas lingüísticas estudiadas (sustantivos → entidades, verbos → relaciones, características → atributos).

## Contexto

Se dispone del siguiente fragmento de especificación de requerimientos de un pequeño taller mecánico:

> "El taller atiende a varios clientes. De cada cliente interesa conocer su DNI, nombre y teléfono. Cada cliente puede llevar varios vehículos al taller para su reparación. De cada vehículo se conoce la matrícula, la marca y el modelo. Cada vehículo puede sufrir varias averías a lo largo del tiempo, y una avería concreta se repara en una única visita. De cada avería interesa registrar una descripción y la fecha en la que se detectó."

## Tareas

1. Enumera los sustantivos del texto que consideres candidatos a **entidad**. Para cada uno, justifica si cumple los tres criterios de entidad (existencia propia, cada ejemplar se diferencia del resto, todos los ejemplares comparten propiedades).
2. Enumera los verbos o expresiones verbales del texto que consideres candidatos a **relación**, indicando qué dos entidades asocian.
3. Para cada entidad identificada en la tarea 1, enumera los atributos que el texto le asigna explícitamente.
4. Indica, para cada atributo identificado, si es **atómico o compuesto** y si es **monovaluado o multivaluado**, justificando tu respuesta con el propio texto.
5. Señala si en el texto aparece algún candidato a atributo de relación (es decir, una propiedad que no pertenece únicamente a una de las entidades, sino al hecho de que se relacionen).
